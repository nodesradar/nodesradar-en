## Frequently asked questions

**What is Free Nodes Radar?**

Free Nodes Radar collects free proxy nodes that people share publicly (VLESS, VMess, Shadowsocks, SSR, Trojan, Hysteria2 and TUIC), removes duplicates and junk, tests each one, names it by country and publishes the working ones as ready-to-use subscriptions.

**Which subscription should I use?**

Use the Clash link for Clash Verge Rev, Clash Party, FlClash, Clash Meta for Android and Stash. Use the V2Ray link for v2rayN, v2rayNG, Shadowrocket, NekoBox, Hiddify and Karing. Use the sing-box link for the official sing-box apps.

**How do I add a subscription?**

Copy the link, open your app, find Subscriptions or Profiles, add a new one, paste the link and update it. Clash apps, v2rayNG and sing-box also support one-click import from this page.

**How often is the list updated?**

Every 6 hours, starting at 22:17, 04:17, 10:17 and 16:17 UTC; each update takes about half an hour. Set your app to update the subscription every 6 hours.

**Why do some nodes not work for me?**

Free nodes go offline often, and the tests run from a data center abroad, so a node can work there but be blocked in your country. Use the auto-select group or your app's latency test to pick a node that works for you.

**Is it safe to use free nodes?**

Whoever runs a node can see where your traffic goes. HTTPS still encrypts page content, but avoid signing in to banking, email or other sensitive accounts through free nodes.

## Note

Free nodes are run by unknown operators who can see the traffic that passes through them. Use them for ordinary browsing only, and never sign in to banking, email or other important accounts through them.
